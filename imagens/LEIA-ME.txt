IMAGENS DAS SECÇÕES
===================

Os ícones desenhados foram removidos. Cada secção do site tem agora
um espaço preparado para uma imagem tua. Basta colocares o ficheiro
nesta pasta com o nome exacto indicado abaixo — não é preciso mexer
no código.

Enquanto um ficheiro não existir, a imagem correspondente fica
simplesmente escondida. Nunca aparece um ícone partido no site.

Nomes dos ficheiros
-------------------
  intro.png           → por baixo de "Vamos casar" (topo, mais pequena)
  contagem.png        → secção Contagem Decrescente
  noivos.png          → secção Os Noivos
  missa-festa.png     → secção Missa & Festa (título)
  missa.png           → cartão "Missa"
  festa.png           → cartão "Festa"
  como-chegar.png     → cartão "Como Chegar"
  rsvp.png            → secção RSVP
  lista.png           → secção Lista de Casamento
  onde-ficar.png      → secção Onde Ficar
  o-que-visitar.png   → secção O Que Visitar
  rodape.png          → rodapé (mais pequena)

  prendas/            → subpasta com as imagens das prendas
    lua-de-mel.png    → prenda "Lua de Mel"

Formato recomendado
-------------------
- Formato: .png com fundo transparente resulta melhor (assenta sobre
  o creme do site sem caixa branca à volta). .jpg, .svg e .webp também
  funcionam — se usares outra extensão, muda o nome dentro do
  index.html (procura por "imagens/").
- Tamanho: cerca de 400 px de largura chega para as imagens das
  secções; 600 px para as prendas.
- Proporção: as imagens das prendas ficam recortadas num quadrado,
  por isso convém que sejam quadradas ou perto disso.

Como adicionar uma prenda nova
-------------------------------
1. Coloca a imagem em imagens/prendas/ (ex: maquina-cafe.png).
2. Abre o index.html e procura a secção "PRENDAS".
3. Copia o bloco <article class="prenda"> ... </article> e muda:
     • o src da imagem   → imagens/prendas/maquina-cafe.png
     • o <h3>            → nome da prenda
     • a linha "prenda-valor" → o valor (ex: 120 €)
     • a linha "prenda-desc"  → uma descrição curta (podes apagar)
4. A grelha ajusta-se sozinha ao número de prendas.
